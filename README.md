Review System Web Application

Overview
This project is a simple and modern review submission system created using HTML, CSS, and JavaScript. Users can submit a review by entering their username, rating, and comment. All reviews are saved in the browser using Local Storage and remain available even after refreshing the page. The design includes a dark modern UI, fixed-height form section, and a scrollable review display section.

Features
1) Add reviews with username, comment, and rating
2) Each review stores the exact date and time of submission
3) Reviews are displayed in a modern card layout
4) Review panel scrolls independently
5) Responsive UI layout
6) Uses Local Storage for storing reviews
7) Fully front-end project without backend

Technologies Used
1) HTML
2) CSS
3) JavaScript
4) Local Storage API

File Structure
1) index.html
2) style.css
3) script.js

How It Works
1) User fills in their username, comment, and rating.
2) On submit, JavaScript captures the details, adds the timestamp, and saves the review in Local Storage.
3) Reviews are loaded dynamically and displayed on the right side in styled cards.
4) The review section scrolls vertically when multiple reviews are added, keeping the layout stable.

Setup Instructions
1) Download or clone all project files.
2) Ensure index.html, style.css, and script.js are in the same folder.
3) Open index.html in any modern browser.
4) Start submitting reviews.

Future Enhancements
